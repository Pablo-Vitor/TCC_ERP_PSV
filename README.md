# PSV ERP — TCC 2027

**Tema:** Projeto e avaliação de uma arquitetura modular de ERP para uma indústria de solados.

Trabalho de Conclusão de Curso de Engenharia de Software, com estudo de caso na PSV Solados, indústria de solados de borracha vulcanizada.

- Pablo Vinicius Soares Vitor — matrícula 25235.

## Objetivo e escopo previsto

Projetar e avaliar uma arquitetura modular de ERP para integrar os processos da empresa. A implementação prevista para o TCC abrangerá um núcleo web de programação de prensas, trocas individuais de matrizes, apontamentos incrementais e relatórios de pares prensados.

A avaliação comparará consultas no núcleo digital e nos cadernos quanto ao tempo de consulta, à exatidão dos totais e à rastreabilidade. A implantação completa do ERP, a emissão de NF-e e a automação de máquinas ficam para etapas posteriores.

## Etapa atual

Entrega inicial do tema e do projeto de pesquisa. O desenvolvimento do sistema ainda não foi iniciado. A execução acadêmica está prevista para fevereiro a novembro de 2027.
